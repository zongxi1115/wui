## 使用场景与设计规范

`Sheet` 为复杂页面提供了沉浸式的侧滑工作台空间：

- **Sheet vs Dialog**：Dialog 适合短小精悍的确认决策与警示弹窗；Sheet 纵向空间充沛，适合长篇表单、嵌套代码查看、复杂筛选或审计详情。
- **经典三段式结构规范**：
  - `SheetHeader`：固定顶部，放置标题与上下文摘要。
  - `SheetBody`：中间自适应填满剩余空间，支持纵向流畅滚动。
  - `SheetFooter`：固定吸底，放置保存、提交或取消操作，确保关键按钮不被长内容挤出视口。
- **四向边缘选择**：
  - **Right（右侧）**：桌面端最标准的侧边详情与配置面板。
  - **Bottom（底部）**：移动端触控优选的 Bottom Sheet。
  - **Left（左侧）**：收起式移动端侧栏导航。

## 无障碍与交互 Accessibility

- **WAI-ARIA 规范**：基于 Radix Dialog 语义标准构建，自动挂载 `role="dialog"` 与 `aria-modal="true"`。
- **焦点捕获 Focus Trap**：面板滑出后，焦点被锁定在抽屉内部，键盘用户无法 Tab 到背后被遮罩的元素。
- **焦点恢复**：关闭抽屉后，焦点自动精准回到唤起它的触发按钮。
- **快捷键**：按下 <kbd>Esc</kbd> 即可平滑关闭侧抽屉。
- **动效减弱**：自动检测 `prefers-reduced-motion` 设置，若开启则禁用弹性物理滑行动画，转为瞬时切换。
