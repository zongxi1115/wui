## 使用场景与设计规范

`AiSources` 专用于 AI 联网搜索（Search-augmented Generation）和企业级 RAG 知识库场景：

- **何时使用**：
  - 联网搜索问答（如 Perplexity / SearchGPT 模式）；
  - 基于企业文档、Wiki 或代码库的 RAG 知识检索问答；
  - 需要对生成事实进行权威溯源与防止模型幻觉的场景。
- **何时不应使用**：
  - 基于模型常识的普通对话，若没有检索工具介入无需堆砌无意义引用；
  - 纯系统静态配置项说明。
- **设计最佳实践**：
  - **行内精准标记**：在每一个由外部事实支撑的断言后放置 `AiCitation`，用户无需滑到页面最底部即可直接悬停核查证据；
  - **网格整齐排列**：在底部聚合时，使用 `AiSourcesList` 的自适应网格（Grid），卡片限制行数（`line-clamp`），保持版面整洁；
  - **外链安全属性**：外跳链接统一默认添加 `rel="noreferrer noopener"` 与 `target="_blank"`。

## 无障碍与交互 Accessibility

- **HoverCard 无障碍规范**：
  - `AiCitation` 内部触发器挂载 `role="button"` 与 `aria-haspopup="dialog"`；
  - 具备 `openDelay` (150ms) 与 `closeDelay` (100ms) 防抖保护，避免用户光标掠过时频繁闪烁。
- **键盘导航支持**：
  - <kbd>Tab</kbd>：按顺序聚焦行内引用角标与来源卡片；
  - <kbd>Enter</kbd> / <kbd>Space</kbd>：展开折叠面板或在悬停气泡中打开源文档外链。
- **高对比度焦点环**：
  - 来源卡片与角标在获得焦点时均具备标准的 `focus-visible:ring-2` 高亮轮廓。
