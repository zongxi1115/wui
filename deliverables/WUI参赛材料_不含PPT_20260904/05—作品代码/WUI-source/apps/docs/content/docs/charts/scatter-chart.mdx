## 使用场景

`ScatterChart` 用于判断两个同口径数值变量之间是否存在关系、聚类或离群点。所有数据行应保持相同粒度，通常至少需要 12–20 个有效观测点。
`groupKey` 只应用于有解释意义的分组，不要用唯一 ID 给每个点制造一种颜色。

## 事件

每个点支持指针悬停和键盘聚焦读取，不产生业务事件。需要点击钻取时可在业务层组合数据表或筛选控件。
