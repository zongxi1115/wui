## 使用场景

`AreaChart` 复用 [`LineChart`](/docs/charts/line-chart) 的坐标、提示框、参考线和无障碍能力，只增加面积填充。
适合强调单个连续指标的规模变化；比较多个轨迹时优先使用折线图，表达组成随时间变化时再引入堆叠面积能力。

示例通过 `actions` 组合已有的 `Select` 与 `Button`。图表不重复实现工具栏控件，也不会接管筛选状态。
