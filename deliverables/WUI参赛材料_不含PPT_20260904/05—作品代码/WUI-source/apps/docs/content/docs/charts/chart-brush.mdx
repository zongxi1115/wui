## 使用场景

`ChartBrush` 直接复用现有 `Slider` 的双 Thumb、键盘和触摸交互，只负责返回起止索引。主图的数据切片和请求范围由业务状态控制，
因此它可以与折线、面积、时间序列或其他有序图表组合。
