## 使用场景与设计规范

`Calendar` 与 `CalendarPanel` 适用于需要直观展示**整月时间维度上下文**的业务界面。

- **Calendar vs DatePicker vs CalendarPanel**：
  - **Calendar（日历）**：常驻内嵌于页面，适合表单旁直接操作选日、工作日排期、预约看板。
  - **DatePicker（日期选择器）**：由 Input 触发并以 Popover 浮层弹出 Calendar，适合空间紧凑的标准表单。
  - **CalendarPanel（大型月度日程面板）**：全宽大格视图，承载丰富的团队日程、待办清单与状态色块。
- **平滑物理弹性动效**：当鼠标掠过网格时，悬停胶囊会以弹簧动力学（Spring Physics）平滑跟随；当用户选定日期或切换“今天”时，指示圆点会动态伸缩过渡为全选底色。
- **禁用规则与边界控制**：利用 `disabled` 函数可轻松剔除周末、节假日或不可预约的历史时段。

## 无障碍与交互 Accessibility

- **ARIA 标准**：网格具有 `role="grid"`，星期表头具有 `role="columnheader"`，日期单元格具有 `role="gridcell"`，并在选中项上标记 `aria-selected="true"`，当天标记 `aria-current="date"`。
- **键盘导航矩阵**：
  - <kbd>←</kbd> / <kbd>→</kbd>：在前后一天之间移动焦点。
  - <kbd>↑</kbd> / <kbd>↓</kbd>：在上下周（前移 7 天 / 后移 7 天）之间移动焦点，到达月份边缘时会自动触发翻月。
  - <kbd>Enter</kbd> / <kbd>Space</kbd>：选定当前聚焦的日期。
- **动态无障碍播报**：月份标题配有 `aria-live="polite"`，翻页时屏幕阅读器会自动播报切换后的最新年月份。
- **动效自适应**：悬停跟随与月份滑入完全监听 `prefers-reduced-motion`，减弱动效时直接即时切换。
