## 使用场景

`ComposedChart` 只在两个不同单位确实共享横轴、且关系值得并置时使用双轴。左右轴都必须在副标题中明确单位，避免读者把不同尺度的形状误认为直接相关。
每个序列通过 `type` 选择柱形或折线，通过 `axis` 选择纵轴。
