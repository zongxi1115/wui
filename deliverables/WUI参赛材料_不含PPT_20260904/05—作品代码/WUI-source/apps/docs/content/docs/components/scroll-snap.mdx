## 使用场景与设计规范

`ScrollSnap` 适用于**全屏幻灯片、移动端横向滑块、财务仪表盘指标卡轮播**：

- **纯原生性能 0 JS 开销**：底层完全由浏览器原生 CSS `scroll-snap-type` 与 `overscroll-behavior` 处理，无需加载庞大的第三方滑块库，触控与惯性极其丝滑。
- **防止过冲（scroll-snap-stop: always）**：对关键章节配置 `stop={true}`，确保用户即使用力猛滑也不会漏掉核心信息。

## 无障碍与交互 Accessibility

- **键盘导航友好**：用户可以使用键盘方向键 <kbd>↑</kbd> / <kbd>↓</kbd> / <kbd>←</kbd> / <kbd>→</kbd> 以及 <kbd>PageUp</kbd> / <kbd>PageDown</kbd> 逐页对齐切换。
- **触控手势原生支持**：在 iOS 与 Android 触控屏上完美保留弹性回弹（Rubber-banding）物理直觉。
