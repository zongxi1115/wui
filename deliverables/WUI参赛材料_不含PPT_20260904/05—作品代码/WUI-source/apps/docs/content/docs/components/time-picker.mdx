## 使用场景与设计规范

`TimePicker` 适用于**精确时刻输入**（如会议开始时间、课程时段、每日定时提醒、营业时间段）。

- **TimePicker vs Select vs DatePicker**：
  - **TimePicker（时间选择）**：专为时分秒刻度设计，分栏滚动选择并可自由控制分钟精度（1/5/15/30 分钟）。
  - **Select（下拉选择）**：适合固定稀疏的几个粗粒度预设项（如“上午 9:00”、“下午 2:00”）。
  - **DatePicker（日期选择）**：面向年月日维度的日历日期选择。
- **数据格式统一规范**：无论前台 `hourCycle` 设置为 12 还是 24 小时制，`onValueChange` 回调输出的数值均始终维持标准的 **24 小时制 `HH:mm` 格式**，避免后端数据存储和业务逻辑处理产生歧义。
- **草稿确认机制**：用户在浮层列中切换时仅暂存为内部 Draft 状态，只有点击“确定”按钮才会正式提交生效；若用户点击外部区域关闭，已选时间将自动恢复，防止误触。

## 无障碍与交互 Accessibility

- **ARIA 规范**：触发按钮挂载 `role="button"`、`aria-haspopup="dialog"`；分栏列内的可选项均挂载 `role="button"` 与 `aria-pressed` 反映当前激活状态。
- **键盘支持**：
  - <kbd>Tab</kbd>：在时、分、时制分栏以及确定按钮之间顺序导航。
  - <kbd>Space</kbd> / <kbd>Enter</kbd>：选定时分数值或激活确定按钮。
  - <kbd>Esc</kbd>：取消修改并立即关闭时间选择弹出层。
- **平滑高亮动效**：选中的时间胶囊背景使用 Framer Motion `layoutId` 进行物理弹簧过渡，在开启减弱动态效果时平稳退化。
