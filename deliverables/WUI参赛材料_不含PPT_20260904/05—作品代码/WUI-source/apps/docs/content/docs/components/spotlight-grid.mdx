## 使用场景与设计规范

`SpotlightGrid` 适用于**科技感控制台卡片、开发者工具看板、产品特性介绍区**：

- **CSS 变量动态驱动**：坐标直接通过 `--grid-x` 与 `--grid-y` 注入至 `mask-image`，不产生 React 状态重渲染，帧率始终保持 120 FPS。
- **触控屏自动静默**：检测到 `touch` 触控类型时不会显示不自然的固定光斑，保持移动端清爽。

## 无障碍与交互 Accessibility

- **层级穿透**：聚光图层全部为 `pointer-events-none`，底层与内部的表单项、按钮可以正常操作。
- **无障碍树忽略**：网格背景图层默认标记 `aria-hidden="true"`，不产生任何无障碍干扰。
