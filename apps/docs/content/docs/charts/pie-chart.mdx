## 使用场景

`PieChart` 用于少量类别的粗略构成比较。默认使用饼图；传入 `innerRadius` 后切换为环图，并可通过 `centerContent` 放置总量。
类别超过五项时应合并为 Top N 与“其他”，需要精确比较时改用堆叠条形图或表格。

## 事件

扇区支持指针悬停和键盘聚焦读取，不产生业务事件。每个类别仍会输出到辅助技术可见的数据表。
