## 使用场景

普通堆叠用于同时查看总量和组成，`normalize` 用于比较构成比例。序列应共享同一单位和分母；正负贡献、瀑布桥接等场景不要套用普通堆叠。
点击业务钻取可使用 `onValueSelect`，键盘聚焦仍能逐段读取数据。
