## 使用场景

`HorizontalBarChart` 是 `StackedBarChart` 的横向薄封装，适合排序后的排名、长产品名称和 5–10 个分类比较。
单指标时只传一个序列，不要为了给每行制造不同颜色而重复分类维度。
