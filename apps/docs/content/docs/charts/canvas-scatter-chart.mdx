## 使用场景

数据达到数百或数千点、SVG 节点开始影响交互时使用 `CanvasScatterChart`。提示框仍使用 DOM 渲染，原始数据仍输出到辅助技术可见表格。
需要精确键盘逐点浏览时继续使用 SVG `ScatterChart`；Canvas 版本更适合形状、密度和离群点扫描。
