## 使用场景

`StackedAreaChart` 用于组成随时间变化，并且各序列能合理相加为一个总量的场景。需要比较每条轨迹本身时，应改用折线图。
`normalize` 会将每个横轴节点转换为 100%，用于观察份额变化。
