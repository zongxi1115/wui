## 使用场景

`Histogram` 对连续数值进行等宽分箱，并复用 [`BarChart`](/docs/charts/bar-chart) 的坐标、提示框和无障碍能力。
它用于观察偏态、集中区间和长尾，不用于比较名称型分类；多个群组的分布比较应改用箱线图或分面直方图。

## 事件

图表不产生业务事件。通过 `bins` 调整分箱数量，通过 `domain` 固定多个直方图之间的可比范围。
