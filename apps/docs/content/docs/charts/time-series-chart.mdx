## 使用场景

与等距分类折线图不同，`TimeSeriesChart` 会根据时间戳间隔定位数据点。`scale="log"` 适用于跨多个数量级且全部为正数的指标，不能用于零值或负值。
`renderTooltip` 与 `renderLegend` 可替换默认内容，但外层间距、颜色和信息密度仍建议沿用现有图表样式。
