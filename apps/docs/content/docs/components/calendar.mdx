## 组件作用

`Calendar` 适合需要直接呈现月份上下文的日期选择、排期和预约场景。它内置相邻月份日期、今天标记、禁用区间和方向键导航；如果界面空间有限，应使用由它组合而成的 DatePicker。

## 事件

`onValueChange(date)` 在选择日期后触发；`onMonthChange(month)` 在切换月份时触发。组件同时支持受控与非受控模式。

选中背景会在日期之间弹性移动；当天的小圆点在被选中时原地展开为完整背景。鼠标经过日期网格时，轻量悬停层会在格子之间平滑跟随，并在系统开启“减少动态效果”时自动降级。

## 扩展使用

通过 `min`、`max` 或 `disabled(date)` 限制可选范围；将 `showOutsideDays` 设为 `false` 可隐藏相邻月份日期。业务应在组件外呈现预约余量或日程摘要，避免让每个日期格承载过多信息。
