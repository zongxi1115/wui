## 组件作用

`Select` 从一组互斥选项中选择一个值。浮层使用克制的淡入与短距离弹簧位移建立层级，不额外堆叠玻璃材质或重阴影；搜索型或允许自由输入的场景应使用 Combobox，而不是 Select。

## 组件属性

核心部件包括 `Select`、`SelectTrigger`、`SelectValue`、`SelectContent`、`SelectItem`、`SelectGroup` 与 `SelectLabel`。Trigger 额外提供 `size="sm | default | lg"`。

## 事件

- `onValueChange(value)`：选中项变化后触发。
- `onOpenChange(open)`：浮层打开或关闭时触发。
- `SelectItem` 支持 Radix 提供的选择、焦点与键盘事件。
