## 使用场景

`Checkbox` 用于在一组互不排斥的选项中选择零项或多项，也适合表示“同意条款”这类需要用户明确确认的布尔值。
多个选项可以同时选中；如果用户只能从多个选项中选择一项，应使用 `RadioGroup`。

勾选状态由调用方保存。将多个复选框放入表单时，标签应说明具体选项，不能只依赖选中颜色区分状态。

## 事件

`onCheckedChange(checked)` 在状态变化后触发，值可能是 `true`、`false` 或 `"indeterminate"`。受控用法下，
回调需要同步更新 `checked`，否则点击后界面不会保持新状态。其余键盘、焦点与表单属性会透传到底层 Radix Root。

## 扩展用法

使用 `checked="indeterminate"` 表示一组子选项只选中了其中一部分，适合“全选”复选框。父项变为不确定状态时，
应在子项数量变化后重新计算，而不是把它当成第三个永久状态。使用 `size="sm | default | lg"` 调整控件尺寸，
文字标签应通过原生 `label` 与控件关联。
