## 使用场景

`mode="highlight"` 将一段文字按词从弱化色逐步过渡到前景色，适合叙事型短段文案；`mode="reveal"` 把单词或显式换行放入遮罩，
随滚动向上揭示。与一次性播放的 `TextEffect` 不同，它的状态始终由当前滚动位置控制，可以正向或反向回放。

这类效果适合标题、引导语和重点段落，不适合整篇正文。文字仍应在没有动画时完整可读。

## 使用说明

按行揭示时在字符串中插入换行并设置 `per="line"`。`range` 控制整组片段占用的进度区间，`overlap` 控制相邻片段同时过渡的程度。
逐词高亮更适合短段落，不要用于正文的每一个自然段，也不要把关键信息设置为必须滚动才能看到。
