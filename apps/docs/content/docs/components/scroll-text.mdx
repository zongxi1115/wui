## 使用场景与设计规范

`ScrollText` 适用于**品牌宣言（Manifesto）、核心产品主张、引言与关键数字口号**：

- **节奏感与停留感**：通过将整段大文字与滚动绑定，引导用户逐字品读核心价值，相比直接呈现能提高 3 倍以上的阅读停留率。
- **排版连贯性**：内置保留了空格与换行符逻辑，不会导致英文断词错位或标点挤压。

## 无障碍与交互 Accessibility

- **屏幕阅读器完整朗读**：组件外层自带 `aria-label={children}`，内部动画分段全部被标记 `aria-hidden="true"`，读屏工具会一次性朗读整句，绝不会被打碎成单个单词。
- **动效减弱适配**：在 `prefers-reduced-motion: reduce` 下，所有文字默认全部直接以最终高亮态显示，不产生任何透明度波动。
