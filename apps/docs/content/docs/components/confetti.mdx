## 组件作用 · What it's for

`Confetti` 为核心里程碑操作提供具有成就感的即时视觉反馈。

### 适用场景
- **目标达成与等级提升**：用户完成挑战、表单提交成功或积分升级。
- **支付与购买成功**：电商结算或 SaaS 订阅完成时的庆祝。
- **免除外部冗余依赖**：纯原生 Canvas 与 requestAnimationFrame 实现，轻量零负担。

### 何时不建议使用
- 避免在常规高频操作（如普通按钮点击或翻页）中滥用，以免分散用户注意力。

## 事件 · Events

- 支持通过 `fireConfetti({ particleCount, spread, origin })` 随时在任意异步回调中命令式触发。
- `fireConfetti` 返回一个清理函数，调用后立即停止动画并移除画布，适合在组件卸载时调用。

## 拓展使用 · Extended usage

可自定义 `colors` 传入品牌主题色，或控制 `origin` 与 `angle` 实现从按钮位置、屏幕两侧或底部发射粒子。粒子物理按真实帧间隔归一化，在 60Hz 与 120Hz 屏幕上速度一致；每片纸屑会随机翻转与摆动，模拟真实飘落。
