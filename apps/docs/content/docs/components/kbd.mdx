## 使用场景

`Kbd` 用于展示单个键位，`KbdGroup` 用于排列组合快捷键。它只负责说明操作方式，不可点击，也不应替代 Button。
例如“保存”是操作按钮，“Ctrl + S”是对该操作的键盘提示，两者应分别承担交互和说明职责。

## 属性

<PropsTable name="kbd" />

`Kbd` 继承原生 `<kbd>` 属性，并提供 `size="sm | default"`；`KbdGroup` 继承原生 `<span>` 属性。
快捷键文本由业务层决定，组件不会根据操作系统自动把 `Ctrl` 转换为 `⌘`。

## 事件

键盘提示本身不触发操作，但原生属性仍会透传。需要响应快捷键时，应在页面或功能逻辑中注册键盘事件，
并同时处理输入框、编辑器等不应拦截快捷键的场景。

## 扩展用法

组合键使用多个 `Kbd` 放入 `KbdGroup` 中。组合只显示符号时，应为容器提供清晰的 `aria-label`，
让读屏器能读出完整操作。

```tsx
<KbdGroup aria-label="Shortcut: Control K">
  <Kbd>Ctrl</Kbd>
  <Kbd>K</Kbd>
</KbdGroup>
```
