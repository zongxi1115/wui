## 使用场景

`Slider` 用于音量、亮度、缩放和数值范围等连续调整。它适合用户可以在一段范围内快速试出合适值的场景；
需要输入精确数字时，应同时提供数值输入框或使用 Number Input。

已选区使用主题主色，滑块保持为轨道内的小圆点；键盘聚焦时会为整条轨道增加清晰的焦点轮廓。

## 事件

`onValueChange(values)` 会在拖动或键盘调整期间连续触发，适合实时更新预览；需要只在操作完成后提交时使用
`onValueCommit(values)`。组件支持受控和非受控用法，范围模式下回调始终返回数值数组。

## 扩展用法

使用 `showValue="hover | always | never"` 控制浮动标签，通过 `formatValue` 添加百分号、单位或自定义内容。
通过 `marks` 传入刻度值数组；传入两个值即可得到范围选择器。方向键会按 `step` 调整数值，Home 和 End 可快速移动到范围边界。

### 交互状态与范围
