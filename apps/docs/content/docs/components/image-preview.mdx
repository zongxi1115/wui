## 使用场景

`ImagePreview` 用于在不离开当前页面的情况下查看图片细节。缩略图是可聚焦的触发器，全屏预览通过 Dialog 管理焦点、
Escape 关闭和标题。它适合相册、附件、设计稿和商品图；需要编辑、裁剪或批注时，应使用专门的图片编辑器。

## 属性

<PropsTable name="image-preview" />

`previewSrc` 可以提供单独的高清图片地址，未指定时沿用 `src`。通过 `minZoom`、`maxZoom` 和 `zoomStep` 调整缩放行为；
通过 `thumbnailClassName` 和 `previewClassName` 分别控制缩略图和大图样式。

## 事件

- `onOpenChange(open)`：预览打开或关闭时触发，支持受控和非受控状态。
- 缩放按钮也支持 `+`、`-` 快捷键，按 `0` 重置缩放和旋转。
- Escape、背景点击和焦点管理会关闭或约束预览；放大后可以拖动图片查看边缘细节。
- 其余按钮属性会透传给缩略图触发器。

## 扩展用法

### 简洁预览

<ComponentPreview name="image-preview-minimal" />

设置 `showToolbar={false}` 可以隐藏变换操作，仅保留查看和关闭能力。传入 `downloadName` 时才会显示下载按钮；
如果产品不允许保存图片，不要传入该属性，以免暴露一个无法完成的操作。
