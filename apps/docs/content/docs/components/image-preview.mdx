## 使用场景与设计规范

`ImagePreview` 专为**电商详情、作品集画廊、附件凭证与设计稿核对**设计：

- **分级加载优化带宽**：对于动辄数兆的高清原图，缩略图使用小图 `src`，灯箱大图传入 `previewSrc`，实现首屏飞速加载与灯箱高清呈现的双赢。
- **拖拽平移视口边界约束**：当图片放大超过屏幕视口范围时，自动激活鼠标抓手拖拽（Drag to pan）模式，并内置弹性边界吸附，防止图片被拖出屏幕视野之外。
- **极简 vs 全功能**：如果不希望用户旋转或下载图片，设置 `showToolbar={false}` 即可获得类似 Medium 或 iOS 相册的极简沉浸式阅读预览体验。

## 无障碍与交互 Accessibility

- **Radix Dialog 焦点管理**：打开灯箱时焦点自动锁定在弹窗内，关闭后焦点平滑恢复至触发缩略图，防止键盘焦点丢失。
- **快捷键导航**：
  - <kbd>+</kbd> / <kbd>=</kbd>：放大图片比例。
  - <kbd>-</kbd>：缩小图片比例。
  - <kbd>0</kbd>：重置为原始 1:1 比例与 0 度旋转。
  - <kbd>Esc</kbd>：立即退出预览。
- **屏幕阅读器**：内置 `DialogPrimitive.Title`（带 `sr-only` 隐藏但读屏可达）自动播报图片 `alt` 描述信息。
