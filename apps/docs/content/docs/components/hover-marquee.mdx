## 使用场景

`HoverMarquee` 默认展示普通目录行，鼠标进入或键盘焦点进入时，以横向循环的预览带替换原内容。它适合作品索引、案例目录、分类导航和视觉化菜单。
默认目录文字仍应能独立表达目的，预览只是补充，不应成为唯一信息来源。

组件内部复用 `InfiniteSlider`，安装时会自动带上对应依赖。用户开启“减少动态效果”时仍会显示预览内容，但不会持续滚动。

## 使用说明

将目录行放在 `children`，把需要重复滚动的内容放在 `marquee`。通过 `speed` 调整速度，并交替设置 `reverse`，可以形成左右错向的目录节奏。
内容较长时应控制重复数量，避免用户焦点进入后需要等待很久才能看到完整信息。
