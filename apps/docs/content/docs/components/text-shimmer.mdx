## 使用场景

`TextShimmer` 适合“生成中”“加载中”等短暂状态。默认颜色来自 `foreground` 和 `muted-foreground`，因此会自动适配明暗主题。
它只是状态提示，不应替代具体的加载说明或错误信息。

## 事件

组件没有自有事件，并透传底层元素事件。动画会持续循环；用户开启“减少动态效果”时停留在静态渐变状态。

## 扩展用法

通过 `duration` 控制扫过速度，通过 `spread` 调整高光宽度。可以在 `className` 中覆盖 `--shimmer-base` 和 `--shimmer-highlight` 两个 CSS 变量。
