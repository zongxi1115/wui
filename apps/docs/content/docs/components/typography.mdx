## 使用场景

`Typography` 用于产品页面和业务内容中的标题、正文与辅助信息。它建立字号、字重和行高层级，但不负责文档布局；
大段富文本或 Markdown 应使用对应的内容渲染组件。

## 扩展用法

### 列表、引用和行内代码

<ComponentPreview name="typography-elements" />

标题变体会自动选择对应的 `h1` 至 `h4` 元素，正文默认使用 `p`。通过 `as` 可以覆盖元素，通过 `asChild` 可以组合框架链接；
覆盖元素时仍应保持正确的标题层级，不能只根据视觉大小选择标题标签。
