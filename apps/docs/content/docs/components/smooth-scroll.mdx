## 组件作用

`SmoothScroll` 封装 Lenis 官方 React Provider。默认 `root` 模式接管文档滚动；设置 `root={false}` 可渲染独立滚动容器。`options` 会直接传给 Lenis，并默认开启 `autoRaf`。

按照 Lenis 官方建议，在应用入口引入配套样式：

```tsx
import "lenis/dist/lenis.css"
```

## 使用建议

平滑滚动应作为页面级能力只挂载一次，不要在普通卡片中层层嵌套。模态框、代码编辑器和需要原生滚动的区域可使用 Lenis 的 `data-lenis-prevent` 属性。组件默认尊重减少动态效果偏好，此时保留内容并停止滚动插值。

Lenis 的完整选项、推荐 CSS 和集成方式请参考[官方 React 文档](https://github.com/darkroomengineering/lenis/tree/main/packages/react)。
