## 组件作用 · What it's for

`Dialog` interrupts the user to show focused content or ask for confirmation.
It traps focus, is fully keyboard accessible, and closes on `Esc` or overlay
click — all provided by Radix. Reach for it for modal flows; for a lightweight
non-modal message, prefer a toast.

The component is a set of composable parts: `Dialog`, `DialogTrigger`,
`DialogContent`, `DialogHeader`, `DialogTitle`, `DialogDescription`,
`DialogFooter` and `DialogClose`.
