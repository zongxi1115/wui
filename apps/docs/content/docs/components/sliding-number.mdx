## 组件作用

`SlidingNumber` 适合计数器、实时指标、时钟和金额展示。每个数位独立滑动，非数字字符会原样保留；组件为读屏提供完整值而不是逐位朗读。

## 事件

组件没有自有事件，并透传 `<span>` 的原生事件。修改 `value` 即会触发过渡；减少动态效果时数位立即更新。
