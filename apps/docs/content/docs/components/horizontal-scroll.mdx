## 组件作用

`HorizontalScroll` 测量轨道溢出宽度，将同等距离加入页面高度，并在区块经过时固定视口、移动内部轨道。它适合案例画廊、时间线和横向章节，不会改变子元素的结构。

## 使用建议

直接子内容需要明确宽度并设置 `shrink-0`。不要把表单、长文本或需要大量垂直浏览的内容放进横向轨道。减少动态效果开启后，组件回退为普通的横向可滚动容器，内容仍然可访问。
