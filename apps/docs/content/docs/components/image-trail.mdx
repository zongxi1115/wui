## 使用场景与设计规范

`ImageTrail` 适用于**创意设计工作室主页、作品集画廊、品牌互动 Hero 展区**：

- **智能节流与垃圾回收**：内置欧氏距离计算与 `setTimeout` 定时器清理机制，未达到移动阈值时不会产生多余渲染。
- **轻量旋转与物理弹跳**：新生成的拖尾项自动带有轻微随机旋转与入场缩放，显得自然灵动。

## 无障碍与交互 Accessibility

- **移动端自动静音**：在触控屏幕（`touch`）上自动禁用拖尾生成，保证页面正常的上下滑动流畅度。
- **动效减弱适配**：当用户开启 `prefers-reduced-motion: reduce` 时，拖尾生成逻辑被完全旁路，仅展示静态内容。
- **无障碍树纯净**：拖尾项全部标记 `aria-hidden="true"` 和 `pointer-events-none`，不会干扰读屏与点击。
