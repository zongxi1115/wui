## 适用场景

`Form` 为标签、控件、说明与校验提示提供语义化布局和无障碍关联。每个 `FormField` 显式维护校验状态，因此可配合原生表单状态或任意校验库使用。它适合需要一致间距与反馈的产品表单；无需统一字段样式时，原生 HTML 表单即可。

## 事件

- `Form` 会透传 `onSubmit`、`onReset` 和 `onInvalid` 等原生表单事件。
- `FormControl` 保留子控件自身事件，同时补充字段 ID 和 ARIA 关联。
- 修改 `FormField` 的 `invalid` 会显示紧邻控件的 `FormMessage`，并触发适配减少动态效果偏好的轻微纠正提示。

## 扩展用法

使用 `FormSection` 和 `FormLegend` 组织成组信息，并将主次操作放入 `FormActions`。若页面容器已经负责入场动效，可设置 `animated={false}`。
