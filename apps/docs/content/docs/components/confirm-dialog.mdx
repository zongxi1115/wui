## 使用场景

`ConfirmDialog` 将“是否继续”这类二次确认封装成一个声明式组件，避免每次都重复组合 `Dialog` 和 `Button`。
它适合删除、移除、发布或覆盖等具有破坏性、不可逆或影响范围较大的操作。普通的成功提交不需要再增加确认步骤。

确认文案应写清楚对象和结果，例如“删除项目 A？删除后无法恢复”，确认按钮也应使用“删除”而不是模糊的“确定”。

## 扩展用法

组件源码会直接保存在你的项目中，可以按业务扩展。例如，为确认按钮添加异步加载状态，
在操作完成后关闭对话框，透传 `onOpenChange`，或调整底部操作区域的布局。确认回调失败时，应保留对话框并显示错误原因，
不要让用户误以为操作已经完成。
