## 组件作用 · What it's for

`ConfirmDialog` wraps the common "are you sure?" pattern into a single
declarative component, so you don't re-wire `Dialog` + `Button` every time you
need a confirmation. Use it for destructive or irreversible actions.

## 拓展使用 · Extended usage

Because it is plain source in your project, extend it freely — add an async
loading state to the confirm button, forward `onOpenChange`, or swap the footer
layout.
