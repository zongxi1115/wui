## 组件作用

`ScrollSequence` 把每个直接子元素视为一个步骤，在固定视口中根据滚动进度切换。它适合 feature 分步演示、流程解释和一个主体视觉配合多段说明的场景。

## 事件

`onStepChange(index)` 在活动步骤改变时触发，可用于同步外部导航、媒体时间点或分析事件。不要在回调中反向修改滚动位置，以免造成循环更新。

## 使用建议

每个步骤应表达一个独立状态，内容高度尽量稳定。`stepLength` 决定两个状态之间的滚动距离。减少动态效果开启时，所有步骤会恢复为普通纵向内容，避免必须通过滚动动画才能读取信息。
