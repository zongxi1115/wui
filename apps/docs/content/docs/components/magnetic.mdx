## 组件作用

`Magnetic` 根据指针相对组件中心的位置产生少量位移，适合按钮、图标入口和单个行动项。离开组件后会通过弹簧动画回到原位；触摸输入和“减少动态效果”偏好不会触发位移。

## 使用建议

`strength` 控制跟随比例，`maxDistance` 限制最大位移。建议保持较小数值，让反馈可以被感知但不影响点击目标的位置判断。
