### TreeNode 数据结构

`items` 树节点类型定义：

```typescript
export interface TreeNode {
  /** 节点的稳定唯一标识值 */
  value: string
  /** 节点在树中展示的文本或 React 节点 */
  label: React.ReactNode
  /** 子节点列表 */
  children?: TreeNode[]
  /** 是否禁用此节点的展开与选择 */
  disabled?: boolean
  /** 节点名称前展示的图标元素 */
  icon?: React.ReactNode
}
```

## 使用场景与设计规范

`TreeSelect` 适用于从**具有层次组织结构**（如公司部门、知识库分类树、文件系统目录）中选取**单个目标节点**的业务场景。

- **TreeSelect vs Cascader vs Tree**：
  - **TreeSelect（树选择）**：在紧凑表单中使用，浮层展开为树，注重从树中定位单点值。
  - **Cascader（级联选择）**：多列横向展开，强制体现层级路径关系（如省市区）。
  - **Tree（树形控件）**：常驻页面主体布局中，支持大面积展示、多选复选框、拖拽排序等深交互。
- **搜索自动展开祖先链**：用户在 `TreeSelect` 中搜索时，组件会自动过滤出匹配的节点并自动展开其上层的所有父级节点路径，确保用户直观理解搜索结果的上下文。
- **一键清空机制**：非必填表单字段建议保留 `clearable={true}`，方便用户快速取消选择而无需重新展开树进行反选。

## 无障碍与交互 Accessibility

- **ARIA 规范**：触发按钮具有 `role="combobox"`、`aria-expanded` 与 `aria-haspopup="dialog"`；内部树结构遵循 WAI-ARIA `tree` 与 `treeitem` 无障碍规范。
- **键盘导航**：
  - <kbd>Tab</kbd>：在表单字段间切换焦点至触发框。
  - <kbd>Enter</kbd> / <kbd>Space</kbd>：展开树选择浮层，光标自动聚焦至内部搜索框。
  - <kbd>↑</kbd> / <kbd>↓</kbd>：在树节点列表中上下移动聚焦。
  - <kbd>→</kbd>：展开当前聚焦的父节点。
  - <kbd>←</kbd>：收起当前聚焦的父节点，或返回上层父级。
  - <kbd>Esc</kbd>：收起浮层并将焦点送回触发按钮。
- **清空操作无障碍**：清空按钮具有独立的 `aria-label="清空选择"`，支持独立键盘 Tab 聚焦与激活。
