## 使用场景与设计规范

- **适用**：技术文档、AI 生成代码、配置片段与代码评审说明。
- **不适用**：Markdown 长文中的代码围栏由 `Markdown` 组件自动渲染为代码块，无需手动组合。
- **高亮克制**：一次只高亮与当前讲解相关的连续行，避免整段着色削弱层级。

## 无障碍与交互 Accessibility

- **多文件切换**：基于 Radix Tabs，标签支持方向键切换，面板与标签自动关联 `aria-controls`。
- **复制反馈**：复制成功后通过 `role="status"` 播报结果，而不仅依赖图标变化。
- **折叠按钮**：展开按钮带有 `aria-expanded` 并通过 `aria-controls` 指向代码区域。
- **减弱动态效果**：高亮带滑动、图标变换与高度过渡在 `prefers-reduced-motion` 下即时完成。
