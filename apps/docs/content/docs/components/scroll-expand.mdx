## 组件作用

`ScrollExpand` 在指定滚动长度内固定一个视口，通过 `clip-path` 和内部缩放把媒体从留白画框展开到满屏。设置 `direction="collapse"` 可用于首屏缩小、圆角化退场的 Sticky Scale Hero 手法。

## 使用建议

子元素应填满组件尺寸，并自行使用 `object-cover` 或等价布局。`inset` 控制紧凑状态留白，`radius` 控制该状态的圆角，`scrollLength` 决定变化节奏。若内容中包含视频，仍需提供原生播放控制和字幕能力。
