## 组件作用

`GrainOverlay` 使用 SVG `feTurbulence` 生成可重复、与分辨率无关的静态噪声。它没有第三方运行时依赖，默认绝对定位并忽略指针事件，可直接放进任意 `relative` 表面。

## 使用建议

从 `opacity={0.08}` 到 `0.18` 的范围开始，根据底色选择 `soft-light`、`overlay` 或 `multiply`。颗粒是统一材质语言，不要只给某张普通卡片单独添加；大面积铺设前应在低端设备上确认 SVG 滤镜成本。
