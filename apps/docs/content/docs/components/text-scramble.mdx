## 使用场景

`TextScramble` 适合生成、解码或终端语义的短状态。随机字符只是视觉层，读屏器始终获得最终文本；
正文、错误说明和必须立即理解的状态不要使用扰码效果。

## 事件

`onScrambleComplete` 在最终文本完全显示后触发。将 `trigger` 从 `false` 切换为 `true` 可以重播；
业务层不要把完成回调当作请求完成回调，两者的生命周期应分别维护。

## 扩展用法

通过 `characterSet` 限制随机字符风格，例如仅用 `01` 营造二进制效果。`duration` 控制总时长，`speed` 控制随机字符刷新间隔。
