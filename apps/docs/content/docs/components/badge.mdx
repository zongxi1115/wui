## 使用场景

`Badge` 适合展示状态、分类、版本号和其他短文本。它是信息标签，不负责触发操作，也不适合放置一段完整说明。

表示结果或风险时，使用 `info`、`success`、`warning` 和 `destructive`；只表示分类时，使用 `default`、
`secondary` 或 `outline`，避免让用户误以为标签代表告警状态。

需要让标签本身可以跳转时，可通过 `asChild` 将样式组合到链接等单个子元素上，同时保留子元素原有语义。

## 可访问性

徽章默认只是一个行内容器，不会自动向读屏器宣布状态。表达无法从附近文字判断的信息时，请使用清晰的文本，
不要只依赖颜色；例如不要只显示红色圆点，而应同时写出“失败”或“有 3 条未读消息”。
