## 组件作用

`RadioGroup` 用于从两个或更多互斥选项中选择一项。环形边框与全局主色实心圆点保持清晰的选中反馈，同时保留方向键切换、焦点管理与表单语义。

## 事件

`onValueChange(value)` 在选择变化后触发。`RadioGroupItem` 接收必需的 `value`，原生焦点、禁用与表单属性会继续透传。

## 拓展使用

通过 `orientation` 控制键盘导航方向，通过 `disabled` 禁用整组或单项。`RadioGroupItem` 支持 `size="sm | default | lg"`，标签应使用原生 `label` 包裹或通过 `htmlFor` 关联。
