## 使用场景与设计规范

`ContextMenu` 为熟练用户提供高效率的“就地操作”通道：

- **快捷方式而非唯一入口**：右键菜单绝不能成为某个核心功能的唯一操作入口，必须确保在工具栏、行内操作列或详情面板中也有同等功能按钮。
- **与上下文强绑定**：菜单中的选项必须完全围绕当前右键点击的对象（如单个文件、某行数据、当前选区），避免放入全局不相关的设置项。
- **警示操作放底部**：具有破坏性的操作（如“删除”、“移至回收站”）必须配置 `destructive` 警示色，通常放在菜单最底部的独立分割组内。
- **快捷键提示规范**：使用 `ContextMenuShortcut` 展示键盘快捷键提示（如 `⌘C`、`⌫`），仅起引导作用，具体全局快捷键需通过业务代码自行监听。

## 无障碍与交互 Accessibility

- **WAI-ARIA 规范**：基于 Radix Context Menu 构建，自动挂载 `role="menu"`、`role="menuitem"`、`role="menuitemcheckbox"` 等语义标准。
- **键盘导航与快捷键**：
  - <kbd>↑</kbd> / <kbd>↓</kbd>：在各个可用菜单项之间快速转移焦点（自动跳过禁用项与分割线）。
  - <kbd>→</kbd> / <kbd>←</kbd>：展开或收起多级子菜单（SubMenu）。
  - <kbd>Enter</kbd> / <kbd>Space</kbd>：触发当前高亮项的 `onSelect` 操作。
  - <kbd>Esc</kbd>：关闭右键菜单并精准恢复焦点至触发区域。
  - **字符搜索 Typeahead**：在菜单打开时键入英文字符，焦点会自动快速跳至对应首字母匹配的菜单项。
