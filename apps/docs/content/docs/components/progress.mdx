## 组件作用

`Progress` 用于展示下载、上传、同步或处理任务的完成程度。它同时提供安静的线性轨道和紧凑环形布局；不传 `value` 时会显示不确定进度。

## 事件

进度条是只读状态组件，不提供交互事件。使用 `value` 更新完成度，并通过 `aria-label` 或 `getValueLabel` 提供可访问描述。

## 拓展使用

### 颜色与环形进度

<ComponentPreview name="progress-variants" />

使用 `color="primary | blue | success | warning | destructive"` 表达不同语义。`variant="circular"` 切换为环形布局，配合 `showValue` 在环内显示百分比；`size` 会分别调整线性轨道厚度或环形直径。动画会在系统开启“减少动态效果”时自动停用。
