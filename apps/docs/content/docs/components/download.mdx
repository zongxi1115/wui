## 使用场景

`Download` 将文件名、文件大小、进度和操作反馈放在同一个下载入口中，适合报告、资源包、媒体和导出文件。
只有一个简单的小文件时，普通 Button 配合下载图标更轻量，不必使用完整下载卡片。

传入 `href` 可以直接使用浏览器的下载行为；需要请求接口、鉴权或临时生成文件时使用 `onDownload`。
业务方通过 `status` 和 `progress` 控制下载生命周期，组件不会替你发起接口请求。

组件默认根据 `filename` 的后缀显示对应的 Lucide 文件图标。通过 `fileIcon` 可以传入自定义图标，或传入 `false` 隐藏图标。

## 事件

- `onDownload()`：用户激活下载时调用，可返回 Promise；异步任务应在 Promise 结束后更新状态。
- 原生 `onFocus`、`onBlur` 等按钮事件会继续透传。

## 扩展用法

### 紧凑尺寸与状态

<ComponentPreview name="download-states" />

`status` 支持 `idle`、`downloading`、`complete` 和 `error`；`progress` 接受 0–100 的数值。
只有在能计算出实际比例时才显示进度；无法确定进度的请求应保持加载状态，避免显示虚假的百分比。
