## 组件作用

`DatePicker` 用于表单中的单日期输入，并复用 Calendar 的日期规则与键盘能力。需要连续日期、多个日期或时间范围时，应组合专门的范围选择器，而不是在单值接口中塞入数组。

## 事件

`onValueChange(date | undefined)` 在选择或清空日期后触发。选中日期后弹层自动关闭；点击清除按钮不会打开弹层。

## 扩展使用

使用 `locale` 与 `formatOptions` 控制触发器文案；`min`、`max` 和 `disabledDate` 会原样传递给内部 Calendar。表单校验信息应放在触发器下方，而不是放进弹层。
