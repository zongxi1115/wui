## 使用场景

`TextLoop` 用于在一句话中轮换关键词、功能标签或短状态。子项可以是任意 React 节点，但应保持相近尺寸，避免页面布局反复跳动。
轮换内容应表达同一类信息，不要让同一句话在每次切换后改变含义。

## 事件

`onIndexChange` 在索引切换后返回新索引。`trigger={false}` 会暂停自动轮换，原生 `<span>` 事件照常透传。

## 扩展用法

可以通过 `variants` 自定义切换方向，通过 `mode` 调整新旧内容的排序策略。持续循环的文字不应承载必须被读屏即时获知的重要状态；
重要状态应使用静态文本或 Alert 明确呈现。
