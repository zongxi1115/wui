## 组件作用 · What it's for

`AiMessageActions` 提供一套即插即用的 AI 消息交互工具链。

### 适用场景
- **用户反馈采集 (`AiMessageFeedback`)**：点赞/点踩，支持与后端数据打点关联。
- **多版本分支切换 (`AiMessageBranch`)**：用户重新生成后，在 `1 / 3` 版本之间无缝回溯历史回答。
- **快速复制与重试 (`AiMessageCopy` / `AiMessageRetry`)**：带平滑状态过渡的一键剪贴板复制和流式重试触发。

### 何时不建议使用
- 如果仅仅是普通的静态文本展示（非模型实时交互），不需要配置复杂的版本切换与点赞组件。

## 事件 · Events

- `AiMessageFeedback.onChange?: (value: "like" | "dislike" | null) => void`：反馈状态变更回调。
- `AiMessageBranch.onPrev` / `AiMessageBranch.onNext`：分支向前/向后翻页。
- `AiMessageCopy.onCopy`：成功复制代码或文本后的回调。

## 拓展使用 · Extended usage

可与 `AiChat`、`AiChatMessage` 以及 `Markdown` 渲染器自由组合，作为消息卡片底部的标准动作栏。
