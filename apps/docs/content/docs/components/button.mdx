## 使用场景

`Button` 用来触发一个明确的操作，例如提交表单、打开对话框、保存内容或确认选择。按钮文案应直接说明
点击后会发生什么，优先使用“保存”“删除”“添加成员”这类动词，而不是“确定”或“点击这里”。

- 页面跳转应使用真实链接：可以选择 `link` 变体，或通过 `asChild` 组合 `<a>` / 路由链接。
- 删除、移除等不可逆操作使用 `variant="destructive"`，并在按钮附近说明影响范围。
- 只显示图标时使用 `size="icon"`，同时提供 `aria-label`；图标只是装饰时，不要让它承担按钮名称。
- 提交请求期间使用加载状态并暂时阻止重复提交，完成后再恢复按钮操作。

## 事件

### 链接变体（动态下划线）

`link` 变体会在悬停时让下划线滑入，并同步平滑改变文字颜色，无需额外配置。下划线紧贴文字标签
而不是按钮的内边距边界，因此在任何 `size` 下都能保持合适的视觉效果。

<ComponentPreview name="button-link" />

<Callout title="通过 asChild 渲染链接">
  使用 `asChild` 渲染真实链接时，按钮会将元素控制权交给子元素，包裹标签的下划线动画无法应用，
  因此 `link` 变体会回退为普通的 `hover:underline`。如有需要，请直接在 `<a>` 上添加动画样式。
</Callout>

### 动效（可选）

设置 `motion` 属性可以启用轻微的按压和悬停反馈。该功能依赖
[`motion`](/docs/components/motion)，并会在用户开启“减少动态效果”后自动关闭。

<ComponentPreview name="button-motion" />

### 涟漪（可选）

设置 `ripple` 属性可以启用从指针位置向外扩散的点击反馈。它可以与 `motion` 同时使用；
用户开启 `prefers-reduced-motion` 时不会播放动画。使用 `asChild` 时，涟漪效果不会生效。
