## 组件作用 · What it's for

`Button` is the primary way to trigger an action — submitting a form, opening a
dialog, confirming a choice. Use it for anything that _does_ something.

- Reach for the **`link` variant** (or `asChild` with an `<a>`) when the control
  navigates instead of acting.
- Use **`variant="destructive"`** for irreversible actions like delete.
- Use **`size="icon"`** for icon-only buttons, and always include an
  `aria-label` or visually-hidden text for accessibility.

## 事件 · Events

`Button` forwards all native button events because it spreads `{...props}` onto
the underlying element.

<PropsTable
  data={[
    {
      prop: "onClick",
      type: "(event: React.MouseEvent<HTMLButtonElement>) => void",

    },
    {
      prop: "onFocus / onBlur",
      type: "(event: React.FocusEvent<HTMLButtonElement>) => void",
      description: "Focus lifecycle events.",
    },
    {
      prop: "type",
      type: '"button" | "submit" | "reset"',
      default: '"button"',
      description: "Behaviour inside a <form>. Set \"submit\" to submit the form.",
    },
  ]}
/>

<Callout title="asChild changes the element">
  When `asChild` is set, events are attached to the child element you render
  (for example an `<a>`), not to a `<button>`.
</Callout>
