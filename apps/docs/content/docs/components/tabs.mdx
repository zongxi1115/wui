## 组件作用

`Tabs` 在同一页面区域切换同等级内容。选中指示器使用 Motion shared layout 在触发器之间自然滑动，内容则以短促的淡入和位移建立方向感。不要用 Tabs 隐藏必须同时比较的信息。

## 组件属性

`Tabs` 透传 Radix Root 的 `value`、`defaultValue`、`orientation`、`activationMode` 等属性；`TabsList` 提供 `variant="pill | underline"`。

## 事件

- `onValueChange(value)`：当前标签变化后触发。
- 键盘方向键、Home、End 与焦点管理由 Radix 处理。
