## 使用场景

`Kanban` 用于按状态呈现可以流转的工作项，适合任务、线索和内容生产流程。它只管理拖放上下文，不持有业务数据；
排序、权限、乐观更新和持久化都由调用方决定。需要比较固定列和字段时，使用 Table 更合适。

## 事件

卡片跨列放下时触发 `onMove({ itemId, from, to })`。每个 `KanbanColumn` 和 `KanbanCard` 都必须提供稳定的 `value`，
业务层应在回调中更新数据，否则拖动结束后界面会回到原位置。原生拖拽事件仍可通过对应元素监听。

## 扩展用法

列由 `KanbanColumnHeader`、`KanbanColumnTitle`、`KanbanColumnCount` 和 `KanbanColumnBody` 自由组合。移动端默认横向滚动；
需要触屏排序或复杂列内重排时，可以在这些布局原语上接入专用拖拽方案，并自行补充触屏和键盘操作。
