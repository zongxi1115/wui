## 组件作用

`Parallax` 将目标经过视口的进度映射为水平或垂直位移。`distance` 决定起止位置，`scale` 可叠加轻微缩放，适合图片内层视差、标题层级和前后景分离。

## 使用建议

图片内层视差应把 `Parallax` 放在 `overflow-hidden` 的固定画框内，并给内容预留超出画框的尺寸。建议从 `[-32, 32]` 到 `[-72, 72]` 的小范围开始；移动距离过大会让内容显得脱离布局。组件在减少动态效果偏好下保持静止。
