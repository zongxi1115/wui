## 使用建议

- 选项较多时保留搜索框；选项较少时仍可使用相同组件保持表单一致性。
- 触发器只展示前 `maxDisplay` 个选项，其余以数量摘要呈现，避免表单被大量标签撑高。
- 选择面板保持打开，便于连续选择；按 <kbd>Esc</kbd> 或点击外部关闭。
- 层级数据请使用 `Cascader`，单选数据请使用 `Select` 或 `Combobox`。
