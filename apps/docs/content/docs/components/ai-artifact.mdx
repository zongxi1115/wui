## 使用场景与设计规范

`AiArtifact` 用于将 AI 生成的长篇代码、交互式组件、SVG 图表、Markdown 文档或 HTML 原型提升为独立的工作区容器：

- **何时使用**：
  - 代码生成助手（类似 Claude Artifacts / v0 / Cursor Composer 产物面板）；
  - 既需要查看完整源代码、又需要实时渲染交互式 UI 组件的场景；
  - 带有运行日志、编译控制台或多文件切换的 AI 智能工作流。
- **何时不应使用**：
  - 对话中仅两三行的内联代码片段（建议直接使用标准 Markdown 代码块）；
  - 静态只读文档展示。
- **设计最佳实践**：
  - **平滑切换动效**：标签页切换基于 Motion 弹性滑块 (`layoutId`)，视觉连贯高级；
  - **全屏沉浸支持**：在复杂图表或仪表盘生成场景下，提供全屏查看按钮；
  - **沙箱隔离安全性**：若在 Preview 中运行动态生成的外部 HTML/JS，请置于安全的 `iframe` 沙箱中执行。

## 无障碍与交互 Accessibility

- **Tablist 规范 (WAI-ARIA Tabs)**：
  - 标签栏挂载 `role="tablist"`，各触发按钮挂载 `role="tab"` 与 `aria-selected`；
  - 内容面板挂载 `role="tabpanel"`，保证键盘与屏幕阅读器无障碍对应。
- **全屏模态焦点管理**：
  - 进入全屏模式后，高层级置顶并提供明显的退出全屏按钮；
  - 复制成功后按钮具有明确的动效勾选与 `aria-label="已复制"` 提示。
- **键盘导航支持**：
  - <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd>：在标签页与操作按钮之间轮转焦点；
  - <kbd>Space</kbd> / <kbd>Enter</kbd>：激活选中的标签页或触发复制。
