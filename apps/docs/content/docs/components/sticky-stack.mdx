## 使用场景

`StickyStack` 负责计算整组滚动进度，并为直接子级 `StickyStackItem` 注入堆叠顺序。卡片使用原生 `position: sticky` 固定，
较早出现的卡片随滚动进度轻微缩小，后续卡片按更高层级覆盖上来。它适合少量连续叙事卡片，不适合承载需要逐项操作的长列表。

## 使用说明

卡片高度应尽量接近，但内容不必完全一致。`top` 和 `gap` 决定堆叠时露出的顶部边缘，`scaleStep` 决定缩小幅度。
组件依赖祖先拥有足够的滚动距离；放在嵌套滚动容器时，应传入同一个 `container` ref。
