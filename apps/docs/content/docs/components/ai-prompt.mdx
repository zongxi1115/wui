## 使用场景与设计规范

`AiPrompt` 专用于 AI 对话、Copilot 侧边栏和智能体交互场景，它负责组织输入区层级、上下文载入与操作入口：

- **何时使用**：
  - 聊天机器人与 Copilot 对话交互输入区；
  - 包含多模态文件上传、联网搜索、深度推理强度调节等复杂上下文配置的输入场景；
  - 需要 `@` 提及项目文件、数据库表或团队成员的协作工作流。
- **何时不应使用**：
  - 常规单行全局搜索框（请使用 `Command` 或 `Input`）；
  - 表单中的纯文本备注（请使用 `Textarea`）；
  - 社区评论发布框（不需要模型与推理选项配置）。
- **设计最佳实践**：
  - **回车键快捷交互**：遵循“<kbd>Enter</kbd> 发送、<kbd>Shift</kbd> + <kbd>Enter</kbd> 换行”的行业统一交互约定；
  - **加载与打断保护**：在模型流式生成期间，发送按钮应自动切换为“停止生成”按钮，允许用户随时打断冗长回答；
  - **上下文明确可视**：被引用的代码片段或上传的文件应放置在 `AiPromptHeader` 独立卡片中，避免直接堆砌在 placeholder 中。

## 无障碍与交互 Accessibility

- **ARIA 角色与语义**：
  - `AiPrompt` 根元素渲染为标准 `<form>`，便于辅助设备识别提交语义；
  - 当提及菜单展开时，输入框自动挂载 `role="combobox"`、`aria-autocomplete="list"` 以及 `aria-expanded="true"`；
  - 提交按钮会依据 `status` 动态更新 `aria-label`（如“发送消息”或“停止生成”）。
- **键盘导航交互**：
  - <kbd>Enter</kbd>：直接触发表单提交；在提及菜单展开时则选中当前高亮项。
  - <kbd>Shift</kbd> + <kbd>Enter</kbd>：在文本域中插入换行符，不会触发误提交。
  - <kbd>↑</kbd> / <kbd>↓</kbd>：在提及弹层中循环切换高亮项。
  - <kbd>Escape</kbd>：关闭当前打开的提及菜单或模型选择弹层。
- **动效降级**：
  - 按钮文字展开与图标过渡遵循 `prefers-reduced-motion` 系统偏好，开启“减少动态效果”时将立即切换状态。
