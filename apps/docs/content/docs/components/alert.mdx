## 组件作用

Alert 是页面内的持久反馈组件，适合承载标题、较长说明、尾部操作以及需要用户主动关闭的状态。只需要在操作后短暂提示一句结果时，应使用 Message。

## 可访问性

- `warning` 与 `destructive` 默认使用 `role="alert"`。
- 其他变体默认使用 `role="status"`。
- 关闭按钮带有可访问名称，语义也可以通过原生 `role` 覆盖。
