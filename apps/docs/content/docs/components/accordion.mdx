## 组件作用 · What it's for

`Accordion` 适合将大量分步信息、常见问题解答（FAQ）、配置项分组或长篇说明以折叠列表形式组织。

### 适用场景
- **常见问题解答 (FAQ)**：提供紧凑整洁的折叠面板，点击标题展开详细解答。
- **复杂表单与配置分组**：在设置页按模块折叠次要配置项。
- **单选互斥与多开支持**：通过 `type="single"` 或 `type="multiple"` 自由控制展开行为。

### 何时不建议使用
- 如果只有单一独立的展开/折叠块，推荐直接使用更轻量的 `Collapsible`。

## 事件 · Events

- `onValueChange?: (value: string | string[]) => void`：当展开项发生改变时触发的回调。

## 拓展使用 · Extended usage

支持通过 `variant="default" | "bordered" | "separated"` 切换通栏分割、圆角外框以及独立卡片式 3 种视觉形态（见基础示例中的切换）。

### 动效说明

展开与收起时，面板高度基于 Radix 测得的 `--radix-accordion-content-height` 以 300ms 缓出曲线过渡，正文同步淡入并轻微下移，指示箭头平滑旋转；`separated` 形态下展开项的边框会加深以强调当前焦点。系统开启“减少动态效果”时，所有过渡自动关闭。

### 多项展开与受控
