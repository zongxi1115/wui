## 使用场景

`Upload` 将文件选择、拖拽区域和上传反馈放在同一个入口中，适合附件、媒体资源和批量文件上传。示例在上传完成后用
`Download` 展示文件，说明了从选择、上传到取回文件的完整流程。

组件负责文件选择和交互状态，不预设请求地址、鉴权方式或存储服务。只需要拿到文件时使用 `onFilesChange`；
需要组件跟踪上传生命周期时，使用 `onUpload` 并返回 Promise。

## 事件

- `onFilesChange(files)`：用户选择或拖入文件后立即调用，适合由业务层自行上传。
- `onUpload(files)`：选择文件后调用；返回 Promise 时，非受控模式会跟随 Promise 更新上传中、完成或失败状态。
- 原生表单属性以及 `onFocus`、`onBlur` 等输入事件会继续透传到隐藏的文件输入框。

## 扩展用法

### 尺寸与状态

<ComponentPreview name="upload-states" />

`status` 支持 `idle`、`uploading`、`complete` 和 `error`；传入 `progress` 可显示 0–100 的确定进度。
使用 `accept` 限制系统文件选择器中的文件类型，使用 `multiple` 开启多选。类型限制只改善选择体验，服务端仍必须重新校验文件类型、大小和内容。
