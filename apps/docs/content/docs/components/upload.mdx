## 组件作用

`Upload` 将文件选择、拖拽区域和上传反馈放在同一个入口中，适合附件、媒体资源和批量文件上传。示例在上传完成后用 `Download` 展示文件，形成从提交到取回的完整文件流。

组件负责文件选择与交互状态，不预设请求方式。使用 `onFilesChange` 只获取文件，或通过 `onUpload` 返回 Promise，让组件自动展示上传中、完成与失败状态。

## 事件

- `onFilesChange(files)`：用户选择或拖入文件后立即调用。
- `onUpload(files)`：选择文件后调用；返回 Promise 时，非受控模式会跟随其生命周期更新状态。
- 原生表单属性以及 `onFocus`、`onBlur` 等输入事件会继续透传到隐藏的文件输入框。

`status` 支持 `idle`、`uploading`、`complete` 与 `error`；传入 `progress` 可显示 0–100 的确定进度。使用 `accept` 限制系统文件选择器中的类型，使用 `multiple` 开启多选。
