## 组件作用

`SpotlightCard` 记录指针相对组件的位置，用径向背景显露局部色彩。它不引入第三方运行时依赖，适合作品目录、定价区域或需要轻微空间反馈的表面。

## 使用建议

通过 `radius` 调整影响范围，通过 `color` 使用与当前内容有关的低透明度语义色。聚光只应强化现有层级，不能承载唯一的状态或操作提示；触摸输入下内容必须仍然完整可读。
