## 使用场景

`SpotlightCard` 记录指针相对组件的位置，用径向背景显露局部色彩。它不引入第三方运行时依赖，
适合作品目录、定价区域或需要轻微空间反馈的表面。光照只增强已有层级，不会改变卡片内容或点击行为。

## 使用说明

通过 `radius` 调整影响范围，通过 `color` 使用与当前内容有关的低透明度颜色。聚光不能承载唯一的状态或操作提示；
触摸输入下没有指针位置，内容仍必须完整可读。
