## 使用场景

`AiConversationTimeline` 用于内容较长的 AI 对话、Agent 执行记录和连续工作流。静止时，所有轮次收敛为一列等距的灰色刻度，
只用 `level` 区分层级长度，不抢正文注意力；指针靠近时，当前刻度和相邻刻度依次变长、变清晰，并在旁边显示该轮对话摘要卡片。

它是导航控件，不是用于展示审计日志的普通 [`Timeline`](/docs/components/timeline)。页面只有少量消息，或不需要跨段定位时，
不要额外加入时间线。

## 事件

使用 `activeId` 和 `onActiveChange` 同步当前阅读轮次。用户点击刻度时，`onNavigate` 会返回完整条目和序号；
业务层可以在回调中调用 `scrollIntoView`、虚拟列表定位或路由跳转。

组件不会接管滚动容器，也不假设消息 DOM 结构。它既可以接入 `AiChatMessages`，也可以用于已有聊天页面或 Agent 运行记录。

## 动效与无障碍

放大量由指针在刻度列中的纵向位置连续计算：当前刻度最大，相邻刻度按距离逐步减小。长度和不透明度分别使用弹簧过渡，
不会因为每次指针移动都触发 React 组件重渲染。

摘要卡片只有一张，会在刻度之间移动到目标位置；内容交叉淡入，靠近容器顶部或底部时会自动收边，避免溢出。

当前轮次不用高亮色，只用略高的不透明度提示，保持“静止时安静”。用户开启“减少动态效果”后，弹簧会退化为直接切换。
每个刻度都是可聚焦按钮，键盘聚焦同样会显示摘要，当前项通过 `aria-current="step"` 暴露给辅助技术。
