## 使用场景

`TextMorph` 为新旧文本中的相同字符建立布局关联，适合按钮标签、短状态和简短标题。新旧文本越相近，形变越自然；
完全不同的长文本更适合 `TextEffect` 或直接替换。

## 事件

组件没有自有回调，更新 `children` 即会触发布局动画，并透传底层元素的原生事件。业务状态应由父组件保存，组件不会替换外部值。

## 扩展用法

通过 `as="span"` 放入按钮或句子中。视觉字符对辅助技术隐藏，完整的新文本会作为元素标签读取；用户开启“减少动态效果”时直接替换文字。
