## 使用场景

`ProgressiveBlur` 将多个带渐变 mask 的 `backdrop-filter` 图层叠加起来，使模糊强度沿某个方向逐步增加。它适合滚动容器边缘、
图片与文字交界处和固定操作栏后方，用来建立内容层级，而不是遮盖信息。

组件只负责视觉效果，默认忽略指针事件并从无障碍树隐藏。父容器通常需要 `position: relative` 和明确尺寸，
模糊层本身不应放置按钮或链接。

## 事件

组件透传 Motion `div` 的动画和原生指针事件属性。由于它默认用于纯装饰层，一般不应在模糊图层本身绑定交互。

## 扩展用法

使用 `direction` 将最强模糊放在 `top`、`right`、`bottom` 或 `left`。增加 `blurLayers` 会让过渡更细腻，也会提高渲染成本；
建议从 6–10 层和较低的 `blurIntensity` 开始调整。
