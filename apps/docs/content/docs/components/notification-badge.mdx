## 组件作用

`NotificationBadge` 将数字或提示点定位在任意子元素的右上角，适合未读消息、待办数量和新状态提醒。数字 `count` 支持 `max` 封顶，零值默认隐藏；使用 `dot` 时只显示提示点。

`count` 也可以传入 React 节点，因此示例直接组合了 `SlidingNumber`，让未读数变化时产生逐位滑动效果。

## 位置与可访问性

通过 `offset={[x, y]}` 以像素微调提示位置。动态或纯视觉内容应同时提供 `label`，使读屏器能够读取完整含义；被包裹的按钮或链接仍需提供自己的可访问名称。
