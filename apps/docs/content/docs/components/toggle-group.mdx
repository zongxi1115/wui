## 使用场景

`ToggleGroup` 适合视图模式、文字格式和同层级筛选。`type="single"` 表达互斥选择，`type="multiple"` 表达可以同时开启的设置；
如果每个操作都会立即执行且不保留状态，应使用 ButtonGroup。

## 事件

单选模式通过 `value` / `onValueChange` 管理字符串值，多选模式管理字符串数组。每个 `ToggleGroupItem` 的 `value` 必须稳定且唯一。

### 多选格式

组级 `variant` 与 `size` 会传递给所有项目，单个项目仍可覆盖。图标项目需要独立的 `aria-label`，不能依赖工具提示代替名称。
