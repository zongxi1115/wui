## 使用说明

组件输出 HTML；若要在其他位置展示用户编辑的内容，请在服务端或渲染前完成 HTML 清洗。工具栏提供标题、文本样式、列表、引用、代码、链接、附件、图片以及撤销/重做操作，也保留浏览器原生快捷键。当编辑光标位于正文链接或附件链接内时，会在链接上方出现“打开链接”按钮。

附件上传由 `onFileUpload` 接管：将 `File[]` 上传到你的服务，并返回 `{ name, url }` 数组，组件会把链接插入当前光标位置。

图片上传由 `onImageUpload` 接管：返回 `{ url, alt? }` 数组，组件会将图片插入当前光标位置。
