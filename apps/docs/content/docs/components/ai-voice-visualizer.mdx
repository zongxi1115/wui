## 组件作用 · What it's for

`AiVoiceVisualizer` 为语音输入、TTS 朗读以及类似 ChatGPT Voice Mode 的全双工实时语音交互提供细腻的视觉反馈。

### 适用场景
- **实时语音通话与对话界面**：展示静止（idle）、聆听（listening）、思考（thinking）和发音（speaking）4 种状态。
- **声波柱与呼吸光环**：提供 `bars`（跳动均衡器柱）、`orb`（呼吸光球）和 `wave`（正弦声波）三种视觉形态。
- **音频电平实时驱动**：传入 `audioLevel`（0~1）时实时映射到声波振幅与缩放，未传入时自动执行各状态的呼吸平滑动效。

### 何时不建议使用
- 如果仅仅是纯文本的聊天界面且无音频播放或麦克风录入，不需要使用该组件。

## 拓展使用 · Extended usage

可通过 `audioLevel` prop 对接 Web Audio API（`AnalyserNode`）获取的实时麦克风音量，实现高精度的真实声音动态响应。
