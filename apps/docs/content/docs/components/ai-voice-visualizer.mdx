## 使用场景与设计规范

`AiVoiceVisualizer` 为**多模态语音交互（Voice Agent / Realtime API / STT / TTS）**提供灵动、优雅的视觉反馈：

- **4 种生命周期状态对应色彩与动效**：
  - `idle`：低对比度灰色静止，表达“准备就绪但未激活”。
  - `listening`：信息蓝（info）随电平跳动，表达“正在专注捕获用户声音”。
  - `thinking`：前景色波峰依次流过（圆环模式显示旋转弧线），表达“正在理解上下文与调用工具”。
  - `speaking`：前景色随音量振幅起伏，表达“AI 正在实时回传发音”。
- **性能**：动画运行在帧循环中并直接写入样式，`audioLevel` 以 60Hz 更新也不会触发额外的 React 渲染开销。
- **对接 Web Audio API**：推荐通过浏览器的 `AudioContext` 与 `AnalyserNode` 获取麦克风或音频元素的 `getByteFrequencyData`，经过归一化计算后传入 `audioLevel`，达到毫秒级音画同步。

## 无障碍与交互 Accessibility

- **状态语义声明**：外层容器为 `role="img"`，并按状态提供默认 `aria-label`（如「正在聆听」），可通过传入 `aria-label` 覆盖；同时带有 `data-state` 与 `data-variant` 属性。
- **动效降级**：开启 `prefers-reduced-motion` 时帧循环停止，波形直接根据电平渲染静态形态。
