## 使用场景

`Glow` 默认让一条多色渐变光线沿内容四周环绕，并用同一条边缘生成柔和光晕。装饰层不会遮挡内容或拦截指针事件，
适合重点入口、功能展示和需要短暂吸引注意的区域。它不应作为唯一的焦点、错误或选中状态提示。

## 使用说明

默认的 `rainbow` 变体通过 `colors`、`spread` 和 `duration` 调整环绕效果。使用 `variant="solid"` 可以切换到单色呼吸光晕，
并通过 `color`、`glowOpacity` 和 `pulse` 控制外观。用户开启“减少动态效果”时，两种变体都会停止动画。
