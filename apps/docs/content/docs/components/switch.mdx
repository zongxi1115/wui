## 使用场景

`Switch` 用于让设置立即在开启和关闭之间切换，例如通知、隐私或显示偏好。它适合切换后可以马上生效的设置，
并支持鼠标、触摸、键盘和表单行为。

滑块使用轻量的弹簧过渡；用户开启 `prefers-reduced-motion` 后会直接切换到最终位置。不要用 Switch 代替需要“提交 / 取消”
的操作，这类场景应使用 Checkbox 或 Button。

## 事件

- `onCheckedChange(checked)`：状态变化后触发，参数为新的布尔值；受控模式下需要同步更新 `checked`。
- 原生焦点、键盘与表单属性会继续透传到底层 Radix Root。

### 尺寸

受控用法通过 `checked` 和 `onCheckedChange` 管理；非受控用法使用 `defaultChecked`。如果切换会触发异步保存，
应在保存期间明确禁用控件或显示保存状态，避免用户连续点击造成状态与服务端不一致。
