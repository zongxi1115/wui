## 组件作用

`Switch` 用于让设置立即在开启与关闭之间切换，例如通知、隐私或显示偏好。它基于 Radix Switch，支持鼠标、触摸、键盘以及表单语义；滑块通过 Motion 弹簧运动，并在 `prefers-reduced-motion` 下自动静止降级。

不要用 Switch 代替需要“提交/取消”的操作；这类场景应使用 Checkbox 或 Button。

## 事件

- `onCheckedChange(checked)`：状态变化后触发。
- 原生焦点、键盘与表单属性会继续透传到底层 Radix Root。
