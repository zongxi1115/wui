## 组件作用 · What it's for

`Dock` 适合作为桌面端应用全局导航栏、画布控制台工具条或现代营销主页的常驻快捷入口。

### 适用场景
- **桌面级工作台快捷导航**：高频工具的快速触达与悬浮切换。
- **弹簧距离插值**：基于 Motion Spring 动态计算邻近项的放大比例，手感细腻跟手。
- **方向与尺寸自定义**：支持 `horizontal`（水平）与 `vertical`（垂直）两种布局。

### 何时不建议使用
- 在紧凑的移动端触屏视口中，建议使用标准 `Tabs` 或底部导航栏以避免 hover 依赖。

## 拓展使用 · Extended usage

可结合 `DockSeparator` 划分功能模块，通过 `active` 标记当前所在的入口（图标下方显示指示点）。图标放大时底栏自身尺寸保持不变，图标沿垂直于排列方向的一侧溢出，相邻图标被平滑推开；内部 SVG 图标会随按钮尺寸等比放大。

### 垂直工具栏

### 无障碍

- `Dock` 渲染为 `role="toolbar"` 并声明 `aria-orientation`。
- 提示标签在键盘 `focus-visible` 时同样显示；触屏指针不会触发放大。
- 开启“减少动态效果”时，图标保持固定尺寸。
