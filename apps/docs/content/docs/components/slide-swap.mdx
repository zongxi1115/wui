## 组件作用

`SlideSwap` 与逐字符动画不同，它把文字、图标或其他组合内容作为完整的一层进行交换。默认在鼠标浮入时让当前层向上离开，并让副本从下方进入，适合导航链接、按钮标签和目录入口。

## 使用建议

组件只负责视觉内容，实际链接或按钮语义应放在外层。通过 `direction="down"` 可以反转方向，也可以传入 `active` 由外部状态控制交换。
