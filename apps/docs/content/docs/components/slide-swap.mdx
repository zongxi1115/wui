## 使用场景

`SlideSwap` 不会逐字符拆分文字，而是把文字、图标或其他组合内容作为完整的一层进行交换。默认在鼠标进入或键盘聚焦时，
让当前层向上离开，再从下方进入新层，适合导航链接、按钮标签和目录入口。

## 使用说明

组件只负责视觉内容，实际链接或按钮语义应放在外层。通过 `direction="down"` 可以反转方向，也可以传入 `active` 由外部状态控制交换。
如果内容变化会影响操作含义，应同时更新外层元素的可访问名称，不能只改变视觉文字。
