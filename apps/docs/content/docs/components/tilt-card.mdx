## 使用场景

`TiltCard` 将指针在卡片中的位置映射为 X / Y 轴旋转，并用弹簧回到静止状态。内部内容可以通过 `translateZ` 建立少量前后层级，
`glare` 提供可选的光照反馈。它适合单个主视觉或少量作品卡片，不适合高密度的信息列表。

## 使用说明

`maxTilt` 建议保持在 4–10 度，`perspective` 越大透视越平缓。不要给密集列表中的每个操作控件都添加倾斜，
否则会增加视觉噪声和跟踪成本。触摸输入以及用户开启“减少动态效果”时会保持静止。
