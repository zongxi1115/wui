## 使用场景

`HoverPreview` 把列表行与对应的视觉预览组合起来：鼠标进入时在指针旁显示跟随浮层，键盘聚焦时把浮层定位到当前行附近。
它适合作品索引、资源目录和带图的文本导航。预览是补充信息，列表行本身仍必须包含完整名称和可操作语义。

## 使用说明

通过 `offsetX`、`offsetY` 避免浮层遮住指针目标；预览尺寸应尽量固定，减少列表切换时的跳动。触摸输入不会因 hover 打开预览，
键盘用户仍可通过焦点触发。不能把只有 hover 才出现的图片作为唯一的内容说明。
