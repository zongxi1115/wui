## 组件作用

`HoverPreview` 把任意列表行与对应的视觉预览组合，鼠标浮入时在指针旁显示弹簧跟随的浮层，键盘聚焦时则把浮层定位到当前行附近。它适合作品索引、资源目录和带图的文本导航。

## 使用建议

`preview` 只提供补充信息，行内仍需保留完整名称和操作语义。通过 `offsetX`、`offsetY` 避免浮层遮住指针目标；预览尺寸应固定，减少列表切换时的跳动。触摸输入不会因 hover 打开预览，键盘用户仍可通过焦点触发。
