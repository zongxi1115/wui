**wui** is a collection of accessible, composable React components built on
[Radix UI](https://www.radix-ui.com/) and [Tailwind CSS v4](https://tailwindcss.com/).

It is **not** a component dependency. Like shadcn/ui, the source is copied into
your project, so you own and can freely edit every component.

## Highlights

- **You own the code.** Components live in your repo, not in `node_modules`.
- **On-demand.** Pull only what you need with the `wui` CLI.
- **Themable.** Tailwind v4 CSS variables (oklch) with light and dark modes.
- **Documented.** Every component ships a live preview, source, props, events
  and extended examples.

## Quick start

Initialize your project:

<CodeTabs command="wui@latest init" />

Then add a component:

<CodeTabs command="wui@latest add @wui/button" />

Head to [Installation](/docs/installation) for the full setup, or jump straight
to the [Button](/docs/components/button) component.
